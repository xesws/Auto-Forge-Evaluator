\section{Autonomous research result}
\label{sec:part1}

\subsection{Hypothesis}
\label{sec:hypothesis}
Under a single frozen LoRA recipe on a 1.5B instruction-tuned base,
can a ten-example probe decide \emph{which} tasks to fully
fine-tune, and is that decision a binary gate or a ranking for a
budget of $K$ slots?
% this regime: protocol_v2; Qwen2.5-1.5B-Instruct
We pre-register a binary label
$\mathrm{go}\Leftrightarrow\Delta_{\mathrm{full}}>0$ and a
secondary ranking endpoint $\rho(\Delta_{\mathrm{pilot}},
\Delta_{\mathrm{full}})$, with the honesty clause that a
non-significant AUC is published as a negative.
% ANALYSIS_PREREG.md L8--41
A later, declared revision (v2) asks the same questions after
removing post-decision features from the classifier, and quantifies
the \emph{utility} of a perfect gate versus always forging. A
correction to that revision (the addendum) separates the effect of
removing leakage from the effect of one declared bug fix; we
report both.
% ANALYSIS_PREREG_V2.md; ANALYSIS_RESULTS_v2.md; ADDENDUM

\subsection{Method}
\label{sec:method}
\paragraph{Protocol and sample.}
Base model Qwen2.5-1.5B-Instruct~\citep{qwen25}, weights pinned at
birth; LoRA rank 16, $\alpha=32$; sequence 4096; effective batch 16;
pilot $10{\times}100$; full cap 8000 / 3 epochs; eval 200, greedy.
% protocol_v2.yaml
pass@8 ($k{=}8$) is a signal (1600 generations per task), never the
label.
% ANALYSIS_RESULTS_v2.md L53
The sealed sample is $n{=}61$ (11 literature-layer + 50 SuperNI,
seed 20260822): 53 registered go / 8 no-go (87\%).
% AR.md L18, L24; v2 L7
BIRD and APPS are out,
\texttt{excluded for logistics, before any label existed}.
% AR.md L27--30
All numbers below that are not marked ``registered'' come from
\texttt{ANALYSIS\_RESULTS\_v2} and its correction file
\texttt{ANALYSIS\_RESULTS\_v2\_ADDENDUM} (CPU revision; the
addendum supersedes the v2 attribution wherever they differ).
Registered AUC/CI remain the v1 sealed row.

\paragraph{Predictors.}
The \emph{new main} classifier is leave-one-task-out logistic
regression on the pre-decision vector only:
$\Delta_{\mathrm{pilot}}$, base pass@1, base pass@8, headroom,
pilot-loss descriptors, format-compliance of the \emph{base}
split, and $\mathrm{train\_n}$.
% ANALYSIS_PREREG_V2.md item 1; v2 L12--14
$\mathrm{gen\_len.full.median}$ is reported as a post-hoc oracle
upper bound and is \emph{not} used for decisions.
% v2 L18, L36
The registered 12-feature vector (which included that oracle and
$\mathrm{full\_n}$) is kept as the registered row.
% v2 L17; AR.md L15, L36
Intervals are task-level bootstrap 95\% CIs (seed 20260820, $B{=}1000$).
A label-permutation test re-runs full LOTO $N{=}1000$ times
(seed 20260826) and is reported as
$(1+\#\{\rho_{\mathrm{perm}}\ge\rho_{\mathrm{obs}}\})/(1+N)$.
% ADDENDUM section 3 (v2 printed the naive #/N)

\paragraph{One declared bug fix, found after the revision contract.}
The revision code also changed one feature \emph{definition}: the
v1 format-compliance scalar $1-\mathrm{unparseable}/n$ silently
returns $1.0$ for any task whose compliance block carries no
\texttt{unparseable} key. Exactly two of the 61 tasks are like
that --- GSM8K, which v1 special-cased, and MATH, which it missed.
The revision adds the matching MATH branch
($\mathrm{boxed}/n=0.55$).
% ADDENDUM section 1
This is a bug fix, not a task-specific choice, but it was found
\emph{after} \texttt{ANALYSIS\_PREREG\_V2} was written, it is not
one of that page's declared items, and it lands on one of only two
substantive negatives. We therefore report every affected number
under both definitions and never fold its effect into
``removing leakage'' (Table~\ref{tab:auc}).
% ANALYSIS_PREREG_V2.md R1-9; ADDENDUM section 2
We also report L2-CV LOTO, a 3-feature model
$(\Delta_{\mathrm{pilot}}, \mathrm{base\_pass1}, \mathrm{headroom})$,
and a no-pass@8 feature set.
% v2 L19--21
Instruction embeddings (MiniLM, CPU) plus SuperNI
Categories/Source are the semantic control; the original four
scalars are the metadata control.
% v2 L40--41
McNemar exact tests on paired eval jsonl induce a three-way label
(go / no-go / undetermined) as a revision-period analysis; the
registered label stays $\Delta_{\mathrm{full}}>0$.
% v2 L43--47
Sensitivity (b) (drop EM-floor rows) is computed but \emph{not}
used as supporting evidence (wide CI).
% v2 L67; ANALYSIS_PREREG_V2.md

\paragraph{Related work (lite).}
Training-free transferability estimators (LogME, LEEP,
TransRate) score a frozen representation against target labels
without fine-tuning~\citep{you2021logme,nguyen2020leep,huang2021transrate}.
We did \emph{not} run them: they select among source models, whereas
we select among \emph{tasks} given one frozen recipe. That is a
limitation and a listed future comparison.
Multi-fidelity methods (successive halving, Hyperband, learning-curve
extrapolation)~\citep{jamieson2016sh,li2018hyperband} treat cheap
runs as a fidelity axis. Our probe is a \emph{single} fidelity
point; a fidelity scan is future work.

\subsection{Evidence}
\label{sec:evidence}
\paragraph{Finding 1: forging is the default \emph{in this regime}.}
53 of 61 tasks (87\%) have $\Delta_{\mathrm{full}}>0$.
% AR.md L18, L24
This is Qwen2.5-1.5B-Instruct, one LoRA recipe, greedy pass@1, gate
$\Delta_{\mathrm{full}}>0$ --- not a claim about 7B models or full
FT. 23 of 61 tasks have $\mathrm{base\_pass1}=0$; most of those
gains are format unlock (the probe teaches the extractor), not
new reasoning.
% ANALYSIS_RESULTS_v2.md L56

\paragraph{Finding 2: the probe ranks gain, and the ranking has
budget value.}
Spearman $\rho(\Delta_{\mathrm{pilot}},\Delta_{\mathrm{full}})=0.755$,
CI $[0.595,0.864]$ (registered secondary; excludes 0).
% AR.md L16, L48
Partial $\rho$ controlling for $\mathrm{base\_pass1}$ is $0.832$
(residualise the raw deltas on base, then rank; the fully
rank-based partial formula gives $0.777$ --- either way the
ranking is not a restatement of base accuracy).
% v2 L26; analysis_v2.py::partial_spearman
Figure~\ref{fig:budget} is the operational plot. Ranking by
$\Delta_{\mathrm{pilot}}$ and spending a budget of $K$ full
fine-tunes captures $0.42$ / $0.72$ / $0.83$ of all positive-gain
mass at $K{=}10,20,30$, against random $0.16$ / $0.33$ / $0.49$
and oracle $0.45$ / $0.74$ / $0.90$.
% v2 L62--65
At $K{=}20$ the probe is within three points of oracle. 38\% of
tasks have $|\Delta_{\mathrm{pilot}}|\le 0.02$ (a dumb probe);
the ranking still works because the mass sits in the tails.
% v2 L54
Figure~\ref{fig:scatter} shows the same pairing; GSM8K/MATH sit in
Q3 and the EM-floor quartet sits at the origin.

\paragraph{Finding 3: the binary gate, three ways.}
\textit{Registered row.} LOTO on the original 12-feature vector
(including post-decision $\mathrm{gen\_len.full.median}$) has AUC
$0.755$, CI $[0.500,0.929]$, covering 0.5 --- a negative under the
honesty clause.
% AR.md L15, L36
(The point $0.7547$ and Spearman $0.7553$ both print as $0.755$;
that is a rounding coincidence, not one statistic.)
\textit{Revision rows, decomposed.} Dropping the post-decision
features \emph{lowers} the AUC to $0.663$, CI $[0.433,0.839]$,
permutation $p{=}0.057$ --- still a negative. The jump to $0.844$
$[0.733,0.943]$, $p{=}0.002$, comes from the declared MATH
format-compliance fix above: one cell of the $61\times 10$ design
matrix, worth $+0.182$ AUC on its own.
% ADDENDUM section 2, section 3
The leaked feature was \emph{helping} the registered row, so the
v1 negative cannot be read as ``leakage.''
It is read correctly as \emph{over-parameterisation}: 12 features
against 8 negatives. The parsimonious pre-decision model ---
three features, no format-compliance term, and therefore invariant
to both the leak and the fix --- is significant at $0.767$
$[0.646,0.879]$, $p{=}0.004$.
% ADDENDUM section 2, section 3
That row, not $0.844$, is the defensible pre-decision estimate.
L2-CV ($0.875$) and the no-pass@8 set ($0.837$) inherit the same
$+0.15$ dependence on the fix and are reported with their
unfixed values in Table~\ref{tab:auc}.
% ADDENDUM section 2
None of these rows is stable at the second decimal: dropping a
single substantive negative moves the $0.844$ model to $0.685$
(MATH) or $0.714$ (GSM8K), across a jackknife range
$[0.685,0.871]$.
% ADDENDUM section 4
\textit{Utility.} A perfect gate's upside versus always-forging is
$|\sum \text{negative }\Delta|/\sum \text{positive }\Delta = 0.024$.
% v2 L55
Net always-forge is $+16.6$ pass points; oracle-forge is $+17.0$.
McNemar three-way labels are 45 go / 2 no-go / 14 undetermined
($\alpha{=}0.05$, uncorrected). With two significant negatives the
determined-only AUC is not a serious gate estimate.
% v2 L45--46
Figure~\ref{fig:roc} is the pre-decision ROC.

\paragraph{Finding 4: you still have to run the probe.}
Instruction-sentence embeddings plus SuperNI category/source have
AUC $0.512$ $[0.255,0.746]$ --- chance.
% v2 L41
The old four-scalar ``text-only'' AUC $0.309$ is a
\emph{metadata} control whose $\mathrm{eval\_n}$ is constantly 200;
it is not evidence that description features run below chance in
any semantic sense.
% v2 L40
Single-feature $\mathrm{steps\_to\_0.01}$ is $0.748$
$[0.585,0.881]$ (does not cover 0.5; five tests, \emph{not}
multiplicity-corrected).
% v2 L35
$\mathrm{gen\_len.full.median}$ is $0.818$ $[0.528,0.978]$ and is
post-hoc.

\subsection{Primary Result}
\label{sec:primary}
In this regime the probe is a \emph{ranker with measured budget
value}, not a stoplight worth building operations around.
Spending $K{=}20$ full slots by $\Delta_{\mathrm{pilot}}$ harvests
72\% of all positive gain, near the oracle 74\%.
% v2 L64
The registered binary endpoint is negative and stays negative
after the post-decision feature is removed ($0.663$); only a
parsimonious three-feature pre-decision model is significant
($0.767$). Even that is almost useless as a \emph{decision},
because a perfect gate saves 2.4\% of positive-gain mass relative
to always forging.
% ADDENDUM section 3, section 5; v2 L55
The 87\% base rate, 23/61 zero-base format unlocks, and McNemar's
two significant negatives are the same fact: no-go is scarce.
Instruction text does not replace the probe (semantic AUC 0.51).
% v2 L41, L56
We do not reopen BIRD/APPS, do not move the registered go
threshold, and do not treat sensitivity (b) as evidence.
